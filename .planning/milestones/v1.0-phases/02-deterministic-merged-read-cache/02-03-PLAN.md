## Trust Boundaries

| Boundary | Description |
|---|---|
| configured local URL -> private network | Operator authority permits one local origin but must not broaden through redirects or credentials. |
| local/remote HTTP bytes -> verified immutable blob | Location never substitutes for exact content-address verification. |
| verified spool -> local BUD-02 upload | Async population must not race deletion, leak files, buffer content, or fail the serving read. |
| public Nix HTTP listener -> daemon | Internal local-cache egress must not create public write authorization. |
