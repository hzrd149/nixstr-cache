## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator secret file→signer lifecycle | Local keys and NIP-46 session secrets enter a narrow provider and must not enter replay/log state. |

| signer/destination state→PUT authorization | Asynchronous capability state controls whether mutation is reachable. |
