<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| candidate files -> Blossom | Large immutable local files cross an untrusted HTTP transport under ephemeral authorization. |
| signer -> daemon | A local or remote signer returns untrusted event fields despite owning the expected pubkey. |
| relay -> coordinator | Untrusted relay responses claim acceptance of a specific signed event. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01-01 | Spoofing | Blossom possession proof | high | mitigate | Key proofs by candidate, canonical server, and blob hash; require a complete same-server matrix and verified GET fallback for ambiguous HEAD. |
| T-04-01-02 | Tampering | Signed publication event | high | mitigate | Compare every signed field to the persisted template, verify the event locally, and pass the normal publication validator before relay I/O. |
| T-04-01-03 | Repudiation | Relay acknowledgement | high | mitigate | Persist only correlated configured-relay NIP-01 OK responses with ok=true before publication commit. |
| T-04-01-04 | Denial of service | Blob replication | medium | mitigate | Enforce inventory ceilings inherited from Phase 3, bounded concurrency, file streaming, deadlines, and cancellation. |
| T-04-01-05 | Information disclosure | Upload authorization | high | mitigate | Keep authorization request-scoped and exclude headers, tokens, raw errors, and credential-bearing URLs from persistence. |
| T-04-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs; use the already locked dependency graph. |
