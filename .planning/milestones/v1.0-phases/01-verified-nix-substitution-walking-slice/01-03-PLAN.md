**As an** operator, **I want to** point a real Nix client at the daemon and substitute an uncached store path from one valid plaintext Nostr cache, **so that** decentralized cache reads preserve trust, integrity, freshness, and bounded resources.

<objective>
Expand the selected-root slice into a safe, lazy, verified path resolver over hostile Blossom transports.

Purpose: Turn a trustworthy root hash into verified path content without weakening network, integrity, or bounded-memory guarantees.
Output: Pinned manifest codecs/fixtures, ordered source planning, durable quarantine, verified spooling, and bounded traversal.
</objective>
