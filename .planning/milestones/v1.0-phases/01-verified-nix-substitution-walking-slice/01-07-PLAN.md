## Phase Goal

**As a** Nix cache operator, **I want to** point a real Nix client at the daemon and safely substitute an uncached store path from a valid plaintext Nostr-published cache, **so that** I can use a decentralized binary cache without modifying Nix.

<objective>
Close the production-launch and publication-admission gaps with one shipped end-to-end daemon path.

Purpose: Make the already implemented verified read stack reachable through the operator entry point while enforcing the configured trust boundary before durable or reactive admission.
Output: Production relay/composition modules, signal-safe launcher, resilient restore, authorization tests, and stock-Nix E2E through main.ts.

<acceptance_criteria>
- Running main.ts with valid Phase 1 configuration binds the configured listener, admits only an allowed default-cache event, and shuts down cleanly on SIGINT/SIGTERM.
- A validly signed event from a non-whitelisted pubkey or a disallowed raw identity never calls StateRepository.accept and is reported through onReject.
- A corrupt stored event row does not abort startup; the bad selection is cleared while other valid rows restore and policy watermarks remain intact.
- tests/e2e/nix_substitution_test.ts contains no test-owned daemon composition mode and proves stock Nix 2.34.7 substitutes through a child executing main.ts.
</acceptance_criteria>
</objective>
