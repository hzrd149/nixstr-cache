## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted retry rows -> network | Durable endpoint work triggers repeated external side effects. |
| relay stream -> local cache relay | Observed untrusted events may be forwarded to an operator service. |
| environment -> publication metadata | Operator strings define keys, lifetimes, endpoints, and resource ceilings. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-02-01 | Denial of service | Repair supervisor | high | mitigate | Bound attempts/concurrency, cap backoff, schedule only nearest due work, and persist outcomes after every attempt. |
| T-04-02-02 | Tampering | Refresh publication | high | mitigate | Route refresh through the same copied inventory, complete-server proof, signing validation, and relay barrier as ordinary updates. |
| T-04-02-03 | Spoofing | Local relay acknowledgement | high | mitigate | Count its correlated OK only when its canonical URL is explicitly present in publication relays. |
| T-04-02-04 | Information disclosure | Local relay forwarding | medium | mitigate | Forward only verified public events and persist no credentials, auth frames, bunker URLs, or raw relay messages. |
| T-04-02-05 | Denial of service | Publication configuration | medium | mitigate | Validate bounded cardinality, canonical endpoints, positive lifetime, concurrency, and attempt ceilings before side effects. |
| T-04-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs; use the locked Applesauce and RxJS graph. |
