<objective>
Implement a bounded daemon-wide in-memory cache of already verified and decoded
Hashtree manifests, shared by all publisher read resolvers and writable
eligibility reconciliation.

Purpose: Eliminate repeated Blossom fetch/decode work without weakening source
isolation, request budgets, cancellation semantics, manifest integrity, or
bounded-memory guarantees.
Output: A tested `@std/cache@0.2.2`-backed manifest cache, configuration and
environment controls, daemon lifecycle wiring, compact diagnostics, and full
repository verification.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Risk | Required control |
|---|---|---|
| Publisher source plan to shared inflight work | A lower-trust or differently ordered plan could supply work to another caller | Inflight key includes canonical ordered URL/origin/trust/role fingerprint |
| Verified manifest to daemon memory | Hostile publishers can force unbounded retained metadata | Strict decode first, dual entry/decoded-byte LRU bounds, oversized-entry skip |
| Shared work to request accounting | Warm results could evade request resource ceilings | Debit unique-node and validated decoded cost on every request before traversal |
| Caller cancellation to shared loader | One disconnect could disrupt unrelated callers | Caller abort only rejects its waiter; cache-owned daemon abort controls loader |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-p2w-01 | Denial of Service | completed manifest cache | high | mitigate | Enforce entry and aggregate validated decoded-byte LRU limits and skip oversized entries |
| T-p2w-02 | Tampering | inflight deduplication | high | mitigate | Deduplicate only identical hash plus canonical ordered source-plan fingerprint and cache only post-verification decode success |
| T-p2w-03 | Elevation of Privilege | RequestBudget integration | high | mitigate | Charge visit, decoded cost, links, depth, deadline, and output independently for every caller, including hits |
| T-p2w-04 | Denial of Service | cancellation/lifecycle | medium | mitigate | Isolate waiter cancellation, daemon-owned abort, cleanup rejected inflight records, idempotent awaited close |
| T-p2w-05 | Information Disclosure | cache debug logging | low | mitigate | Emit compact bounded counters and abbreviated hashes only; omit manifests and full source URLs |
</threat_model>
