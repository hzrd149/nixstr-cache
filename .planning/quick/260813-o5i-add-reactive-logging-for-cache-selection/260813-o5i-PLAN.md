# Add reactive cache and NAR provenance logging

## Goal

Make cache selection and package-serving provenance visible without exposing
untrusted or secret values.

## Tasks

1. Emit a structured diagnostic for the initial selected cache set and each
   distinct reactive change.
2. Log successful Narinfo/package loads with the winning cache and all caches
   that supplied compatible metadata.
3. Log the exact selected Hashtree publication that serves each upstream NAR
   GET/HEAD, including whether it came from a pinned Narinfo route or fallback
   traversal.
4. Add secret-safe formatter and integration coverage, then run full verify.
