# Remove non-empty cache and extra-relay startup requirements

<objective>
Allow empty read-only and writable-only deployments without weakening relay discovery, write authorization, or publication availability gates.

Purpose: Operators can start an intentionally empty cache, or populate a signer-owned cache from scratch, using bootstrap NIP-65 discovery instead of redundant configured publishers and publication relays.
Output: Relaxed validation, safe empty subscription behavior, reactive signer relay readiness, focused regressions, and corrected NixOS/operator documentation.
</objective>
