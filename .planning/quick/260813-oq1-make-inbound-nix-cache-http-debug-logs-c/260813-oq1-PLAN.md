# Clarify inbound Nix HTTP debug logs

## Goal

Make compact debug output unambiguously show requests arriving at the local Nix
cache listener, including its endpoint/port, while separating inbound request
IDs from outbound fetch IDs.

## Tasks

1. Add separate inbound and outbound correlation ID generators.
2. Include `direction=inbound` and a sanitized local endpoint on request start
   and completion lines.
3. Update compact logging tests and README examples, then verify and commit only
   files owned by this task.
